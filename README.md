# 1/10 Scale Traffic Signal Head

LED boards and firmware for a 1/10 scale 12 in (300 mm) three-section traffic
signal head. Both KiCad projects are generated by a script, not hand-drawn —
edit the `VARIANTS` block in [`gen_signal_pcb.py`](gen_signal_pcb.py) and
re-run. UUIDs are deterministic, so regenerating does not churn the files.

```
python gen_signal_pcb.py ring      # signal-head/
python gen_signal_pcb.py dense     # signal-head-dense/
python gen_signal_pcb.py both
```

## Variants

| | [`signal-head/`](signal-head/) | [`signal-head-dense/`](signal-head-dense/) |
|---|---|---|
| LEDs | 36 (12 per lens, 11.5 mm ring) | 57 (19 per lens, filled aperture) |
| Target optics | frosted diffuser, ~15 mm standoff | clear lens, near-zero standoff |
| Per-LED current | 15 mA | 10 mA |
| Peak draw | ~186 mA (green) | ~190 mA |
| Placements | 72, single-sided | 114, single-sided |

The dense variant is **not** an upgrade — it is a different optical design,
where the dots are the visible image rather than a source behind a diffuser.
Each project's README explains the tradeoff and the photometric modelling
behind the layout.

## Electrical

Both boards are common anode, low-side switched, one resistor per LED:

```
VLED (+9 V) --> R(n) --> LED(n) anode
                         LED(n) cathode --> K_RED / K_AMB / K_GRN --> switch --> GND
```

The switch is off-board — a ULN2003A or logic-level MOSFETs. Neither board can
be driven directly from microcontroller or Raspberry Pi GPIO pins: a single
cathode line carries the whole lens (~186 mA), and `VLED` needs 9 V.

## Layout

| | |
|---|---|
| [`gen_signal_pcb.py`](gen_signal_pcb.py) | generator — schematic, board, placement, routing, BOM |
| [`fill_zones.py`](fill_zones.py) | fills the copper pours via `pcbnew` (run automatically) |
| [`make_jlcpcb.py`](make_jlcpcb.py) | gerbers, BOM and CPL for JLCPCB assembly |
| [`firmware/signal_head/`](firmware/signal_head/) | Arduino sketch — phase cycle plus a mode button |

Both boards pass `kicad-cli` ERC and DRC with zero violations and are fully
routed.
